# IA para Cibersegurança - Estudos sobre LLMs

Este repositório foi criado com o objetivo de armazenar e catalogar os notebooks do Google Colab utilizados durante os estudos e aprendizados na cadeira de **IA em Cibersegurança**. 

## Propósito do Repositório

O foco principal deste espaço é servir como um acervo organizado para consulta, documentando da jornada de aprendizado, experimentos, treinos e testes práticos envolvendo **LLMs (Large Language Models)** e Machine Learning aplicados ao contexto de segurança da informação.
